=========================
Pricelist Report Template
=========================

Pricelist Report Template is a professional Odoo application that helps
businesses generate customer-ready pricelist reports directly from Odoo.

The module provides a clean and printable report layout with HTML preview
and PDF export functionality. Users can generate professional pricing
documents with customer information, quantity-based pricing, and company branding.

=============
Configuration
=============

* Install the Sales application
* Configure Products and Pricelists
* Select Products for the Report
* Generate Preview or PDF Report

============
Key Features
============

* Pricelist Report Layout
* HTML Report Preview
* PDF Report Export
* Quantity-Based Pricing
* Product Description Display
* Unit of Measure (UOM) Display
* Company Logo Integration
* Custom Document Number
