Workflow

Simple and efficient report generation process.

✔ Open the required Pricelist.
✔ Click the Print Variant Report button.
✔ Select the required Product Variants.
✔ Enter Customer Information.
✔ Preview the Pricelist Report.
✔ Export the report as a PDF document.
