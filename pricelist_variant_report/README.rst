=========================
Pricelist Variant Report
=========================

Pricelist Variant Report allows users to generate professional pricelist reports based on product variants directly from Odoo. Users can select variants from a pricelist, enter customer details and quantities, then preview or download the report as a PDF.

=============
Configuration
=============

* Install Sales module
* Create Products and Variants
* Configure Pricelists
* Select variants from the report wizard

============
Key Features
============

* Variant-Based Pricelist Report
* Product Variant Selection Wizard
* Customer Information Support
* HTML Preview
* PDF Export
* Company Branding Support
